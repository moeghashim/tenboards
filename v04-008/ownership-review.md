# Whole-tree ownership review

The final TypeScript AST import audit covers 439 source files, 22 canonical fixture modules and all 22 registered domain reads. Dynamic imports are exempt only inside a createServerFn handler; transitive runtime fixture imports from UI/state/pure helpers fail. Type-only imports do not create a runtime edge. Every fixture module matches a registered domain owner, and every domain is reached by a server-function route loader. Mail/Chat dashboard wrappers load the standalone route in an iframe.

Companion literal-audit.txt and array-audit.json inspect JSX literals/attributes and object arrays across routes, components, data and lib, rather than relying on fixture filenames. The final audit discovered Chat's (24)/(18)/(2) tab counts and May 6, 2026 thread marker, assigned them to original task 005's communication domain, and moved them to typed count metric points and a civil-date display record in task 008 (migration 0011). Their rendered values are unchanged.

Remaining arrays are table column definitions, navigation/menu/control options, chart color/style mappings, computed records from loader data, brand/font/preference registries, or metadata. Remaining numeric literals in JSX are SVG geometry/style/size, form bounds/placeholders, pagination choices, range/window/threshold control descriptions, unit symbols, or simulation calibration/axis labels. They are not observations, business records or KPIs. Risk Ladder 30, Last 6 Months, 12-week trend and the 100% target line describe the existing chart/control presentation. Underlying risk/forecast/revenue/series values and model parameters are loaded.

Patient Monitoring's four named simulation modules remain unchanged from the incumbent. Their waveform/trend templates, deterministic initial phase, calibration/axis labels and live clock/tick mechanics are the sole client-signal exception. Patient identity/bed/clinical values, baseline parameters, alarm content/duration, thresholds and monitor settings are normal read data. The misleadingly named Analytics realtime visitors snapshot is persisted, not exempt. World-atlas geometry is an external map presentation asset, not shipment coordinates.

Retained route data.ts/profile-data.ts/crm.config.ts files now hold types, pure formatting/calculation helpers and UI config only. Removed JSON fixtures are canonical server fixture modules. Auth/system/redirect/error routes have no app-domain dataset; auth stays UI-only. No protected calendar/UI wrappers, navigation/font/preferences registries, generated route file, PLAN or license/provenance file changed.
